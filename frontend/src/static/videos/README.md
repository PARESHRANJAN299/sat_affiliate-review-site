# Videos

Put the home page hero video here. The build uses it automatically; nothing else needs editing.

| File | Needed? | Notes |
|---|---|---|
| `home-hero.mp4` | yes | H.264, 1280 x 720, 10 to 20 seconds, no sound, ideally under 3 MB |
| `home-hero.webm` | optional | smaller VP9 version for browsers that support it |
| `home-hero.jpg` | optional | still frame shown while the video loads |

* The video plays muted, looping, behind the headline and the picture tiles. It is skipped for visitors who ask their device for reduced motion, or who use data saver.
* Use only footage you shot or have a licence for.
* Keep it small: large files slow the page on phones.
